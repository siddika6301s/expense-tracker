AYESHA'S PERSONAL EXPENSE TRACKER MANAGEMENT SYSTEM
====================================================

START HERE (NO INSTALLATION)
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html.
4. The website opens in your browser.
5. Use the left navigation to open Transactions, Categories, Budgets, Reports and Settings.

IMPORTANT - BROWSER-ONLY EDITION
This edition is designed to work by opening index.html directly, without installing Node.js,
Express.js, MySQL, or any other software. It saves data in the browser's localStorage.
Your entries remain in the same browser on the same computer. Use Settings & data > Download
backup to save a copy. Browser-only storage is not a shared MySQL database.

FEATURES
- Dashboard with balance, income, expense, budget remaining and recent transactions
- Add, edit, delete and search transactions
- Income and expense transaction types
- Default categories plus create/delete custom categories
- Monthly category budgets with progress and over-budget warnings
- Monthly reports and category-wise spending breakdown
- Export transactions as CSV
- Backup and restore data as JSON
- Responsive multi-page layout
- Project title includes Ayesha

EXPRESS + MYSQL VERSION
The backend source and four-table MySQL schema are included for your academic project.
To run the real Express/MySQL version, a Node.js runtime and MySQL server must be installed
and running. A plain browser cannot start an Express server or MySQL database from an HTML file.
See backend/README_BACKEND.txt for setup instructions.
